## About the Internship

The internship provided practical, hands-on exposure to web and mobile application development within a professional team environment. The associated project, **Task2Grab**, is a task-based rewards platform where users discover and complete incentivized tasks and earn coins or cash rewards.

My primary contribution was to the **Task2Grab website**, focused on the **Login page** and **Home section**, covering user-authentication-related functionality, UI/UX changes, responsive interface development, and dynamic task-related content. I also contributed to selected parts of the **Task2Grab mobile application**, built on React Native.

---

## My Scope of Work

- Task2Grab website development — primary focus on the Login page and Home section
- User-authentication-related interface work
- UI/UX modifications and refinement
- Responsive interface development
- Handling dynamic task-related UI/content in assigned areas
- Interpreting Figma designs and converting design elements into code
- Contribution to selected parts of the Task2Grab mobile application
- Use of Visual Studio Code, Git and GitHub as part of the development workflow

**Not part of my individual scope:** backend development, API integration, the wallet system, AsyncStorage implementation, and the complete navigation system — these were handled by other team members.
